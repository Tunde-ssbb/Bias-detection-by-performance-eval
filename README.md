# Overview of project code

This repo combines 3 folders which were all used in the preperation of the thesis. Each folder is a self-contained repo, but they are combined here for convenience. For details on code structure and usage please refer to the README files contained in each subfolder root.

- ```Dataset-generation```: Code to generate the benchmark datasets.
- ```Showcase-analysis```: Code to analyse the data for showcase experiments, includes performance and bias metrics and explainability experiment.
- ```Onto-matcher-experiment```: Code for Onto-matcher, including experiment pipelines and analysis.
